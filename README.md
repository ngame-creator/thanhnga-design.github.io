# Dark Creative Portfolio — phiên bản dùng sản phẩm thật

Website tĩnh responsive, gồm 15 ảnh thiết kế được chọn từ ZIP do bạn cung cấp. Có bộ lọc Campaign / Entertainment / E-commerce, phóng to ảnh, menu mobile và chuyển động nhẹ.

## Cập nhật trước khi xuất bản
1. Mở `index.html` để đổi tên hiển thị `PORTFOLIO`, lời giới thiệu và email `your-email@example.com`.
2. Thay liên kết Behance và Instagram mặc định bằng hồ sơ của bạn.
3. Nếu muốn thay ảnh, đặt file ảnh WebP/JPG trong `assets/`, rồi cập nhật đường dẫn `src` và `data-image` ở thẻ `.project-preview` tương ứng trong `index.html`.
4. Tên và nhóm dự án do website gợi ý từ hình ảnh, hãy kiểm tra lại nếu cần tên chiến dịch chính xác.

## Xuất bản miễn phí với GitHub Pages
1. Đăng nhập GitHub tại https://github.com.
2. Tạo repository **Public** tên `username.github.io` (đổi `username` thành tên tài khoản GitHub).
3. Upload toàn bộ nội dung trong thư mục này vào **gốc** repository, gồm `index.html`, `style.css`, `script.js` và thư mục `assets`.
4. Vào Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
5. Sau khi triển khai, mở `https://username.github.io/`.

Để xem trên máy tính, mở `index.html` bằng trình duyệt. Không cần cài đặt Node.js hoặc trả phí hosting. Tên miền riêng là tùy chọn và thường có phí.
